Glance VERSION for Windows

Run Glance.exe; there is nothing to install. Open a picture, PDF or video, or drop one on the
window. Right-click for every command, including Settings.

pdfium.dll reads PDFs (PDFium, Chrome's PDF engine) and libmpv-2.dll plays videos (mpv's engine,
built on FFmpeg). Each is loaded only when you first open a PDF or a video; delete either if you
don't want PDFs or videos.

To make Glance the default app, right-click > Make Glance the default app... and choose Glance for
each kind of file in Default apps. Its files then show Glance's icons in Explorer.

GlanceThumbnails.dll shows the first page of each PDF as its thumbnail in Explorer. Turn it on
with right-click > Show PDF covers in Explorer (Windows asks for administrator permission once).

Settings are kept beside Glance.exe (Glance.ini, Pages.ini, Parameters.ini), so copying this
folder takes them along.
